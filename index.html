Practical 1: Probability Simulations & Law of Large Numbers

📌 Core Theory: Classical vs. Empirical Probability & Law of Large Numbers (LLN)

Empirical probability estimates the likelihood of an event based on real observations (P(E) = n(E) / N). The Law of Large Numbers states that as the number of independent trials N approaches infinity, the empirical probability converges to the theoretical probability.

Question 1

Simulate 100 Coin Tosses & Compare with Theoretical Probability

A fair coin is tossed 100 times. Simulate 100 coin tosses using NumPy. Count the number of Heads and Tails. Calculate the empirical probability of obtaining Head and Tail and compare them with the theoretical probabilities P(H) = 0.5, P(T) = 0.5.

python 3 
import numpy as np

# Set random seed for reproducibility
np.random.seed(42)

# Simulate 100 coin tosses ('Head' or 'Tail')
tosses = np.random.choice(['Head', 'Tail'], size=100)

# Count frequencies
heads = np.sum(tosses == 'Head')
tails = np.sum(tosses == 'Tail')

# Calculate empirical probabilities
prob_heads = heads / len(tosses)
prob_tails = tails / len(tosses)

# Display results
print(f"Heads Count: {heads}")
print(f"Tails Count: {tails}")
print(f"Empirical P(Head): {prob_heads:.4f} | Theoretical P(Head): 0.5000")
print(f"Empirical P(Tail): {prob_tails:.4f} | Theoretical P(Tail): 0.5000")
▶ Expected Terminal Output
Heads Count: 44 Tails Count: 56 Empirical P(Head): 0.4400 | Theoretical P(Head): 0.5000 Empirical P(Tail): 0.5600 | Theoretical P(Tail): 0.5000
💡
Viva / Concept Insight: Why doesn't the empirical probability exactly equal 0.5 for 100 tosses? Because 100 is a relatively small sample size subject to random sample variance. As N increases, random fluctuations average out.
Question 2

Demonstrate the Law of Large Numbers (Sample Sizes 10 to 100,000)

Repeat the coin-toss experiment for sample sizes n = 10, 100, 1,000, 10,000, and 100,000. Calculate the empirical probability of Heads for each sample size and plot the convergence curve against the theoretical probability line (y = 0.5).

python 3 
import numpy as np
import matplotlib.pyplot as plt

sample_sizes = [10, 100, 1000, 10000, 100000]
probabilities = []

np.random.seed(42)
print("--- Law of Large Numbers Convergence ---")
for n in sample_sizes:
    tosses = np.random.choice(['Head', 'Tail'], size=n)
    heads = np.sum(tosses == 'Head')
    prob = heads / n
    probabilities.append(prob)
    print(f"Tosses (n = {n:>6}): Heads = {heads:>5} | Empirical P(Head) = {prob:.5f}")

# Plotting the convergence graph
plt.figure(figsize=(10, 5))
plt.plot(sample_sizes, probabilities, marker='o', color='#0284c7', linewidth=2, label='Empirical P(Head)')
plt.axhline(y=0.5, color='#ef4444', linestyle='--', linewidth=2, label='Theoretical P(Head) = 0.5')
plt.xscale('log')
plt.xlabel("Number of Tosses (Log Scale)")
plt.ylabel("Empirical Probability of Heads")
plt.title("Law of Large Numbers: Convergence of Empirical Probability")
plt.legend()
plt.grid(True, alpha=0.3)
plt.show()
▶ Expected Terminal Output
--- Law of Large Numbers Convergence --- Tosses (n = 10): Heads = 7 | Empirical P(Head) = 0.70000 Tosses (n = 100): Heads = 47 | Empirical P(Head) = 0.47000 Tosses (n = 1000): Heads = 493 | Empirical P(Head) = 0.49300 Tosses (n = 10000): Heads = 5076 | Empirical P(Head) = 0.50760 Tosses (n = 100000): Heads = 49937 | Empirical P(Head) = 0.49937
💡
Viva / Concept Insight: Notice how at n=10, P(Head)=0.70 (30% error), but by n=100,000, P(Head)=0.49937 (under 0.1% error). This proves the Law of Large Numbers.

📌 Core Theory: Parametric Distribution Fitting via Maximum Likelihood Estimation (MLE)

Fitting a probability distribution involves finding parameter estimates (e.g., mean μ and variance σ² for Normal, rate λ for Poisson, scale β = 1/λ for Exponential) that maximize the likelihood of observing the empirical sample data.

Question 1

Normal Distribution: Modeling & Fitting Examination Scores

python 3 
import numpy as np
import matplotlib.pyplot as plt
from scipy import stats

# Fit normal distribution to estimate parameters (mu, sigma)

plt.xlabel("Examination Score")
plt.ylabel("Probability Density")
plt.title("Normal Distribution: Observed Data & Fitted PDF")
plt.legend()
plt.grid(True, alpha=0.3)
plt.show()

print(f"Estimated Mean (μ)              : {mu:.4f} (True: 70)")
print(f"Estimated Standard Deviation (σ): {sigma:.4f} (True: 10)")
▶ Expected Terminal Output
Estimated Mean (μ) : 70.0684 (True: 70) Estimated Standard Deviation (σ): 9.8027 (True: 10)
💡
Viva / Concept Insight: Why must density=True in plt.hist? Because the PDF represents probability density, where the total area under the curve equals 1. Setting density=True normalizes histogram bin heights so area sums to 1.

Practical 3: Joint, Marginal & Conditional Probability on Real Datasets

📌 Core Theory: Contingency Tables, Joint & Conditional Probability

Joint Probability P(A ∩ B) is the probability that both events occur. Conditional Probability P(A | B) = P(A ∩ B) / P(B) is the probability of A given that B has occurred. Two events are statistically independent if and only if P(A ∩ B) = P(A) · P(B).

Titanic: Contingency Table & Survival by Gender

Load the Titanic dataset. Construct a contingency table for sex vs. survival, then estimate: 1) Joint probability P(Female ∩ Survived), 2) Conditional probability P(Survived | Female), 3) Conditional probability P(Survived | Male).

Statistical Independence Test: P(A ∩ B) vs P(A) · P(B)

Test whether Species and Island are statistically independent using: P(A ∩ B) = P(A) · P(B). Let A = Penguin is Gentoo, B = Penguin is on Biscoe Island.

python 3 
import seaborn as sns

df = sns.load_dataset('penguins')
total = len(df)

# Probabilities
p_A = (df['species'] == 'Gentoo').sum() / total
p_B = (df['island'] == 'Biscoe').sum() / total
p_A_and_B = ((df['species'] == 'Gentoo') & (df['island'] == 'Biscoe')).sum() / total

product = p_A * p_B

print(f"P(Gentoo)            : {p_A:.4f}")
print(f"P(Biscoe)            : {p_B:.4f}")

Practical 5: Hidden Markov Models (HMM) & NLP Inference

📌 Core Theory: Hidden Markov Models (HMM) & Sequence Likelihood

An HMM consists of hidden states S (e.g., parts of speech), observable symbols V (e.g., words), initial probabilities π, transition probabilities A, and emission probabilities B. The joint probability of state sequence S and observation O is: P(S, O) = π(s₁) B(o₁|s₁) ∏ A(s_t|s_t-1) B(o_t|s_t).

Practical 7: Bayesian Parameter Estimation

📌 Core Theory: Bayesian Updating & Grid Approximation

Bayes' Theorem updates belief upon observing data D: P(θ | D) ∝ P(D | θ) · P(θ). When dealing with large binomial counts, log-likelihood ln L(θ) = s ln(θ) + (n-s) ln(1-θ) prevents arithmetic underflow. The Maximum A Posteriori (MAP) estimate maximizes P(θ | D).

Question 1

Estimate Female Survival Rate θ on Titanic via Bayesian Grid Updating

Extract female passengers on Titanic (n=314, s=233 survived, 81 died). Discretize parameter θ in [0.1, 0.9]. Set a uniform prior P(θ) = 1/9. Compute Binomial log-likelihood, likelihood, unnormalized posterior, and normalized posterior. Report the MAP estimate and posterior mean.

python 3

import seaborn as sns
import numpy as np
import matplotlib.pyplot as plt

s = int(female.sum())
nonsurv = n - s

print(f"Total Female Passengers (n) : {n}")
print(f"Survived (s)                : {s}")
print(f"Not Survived (n - s)        : {nonsurv}")

# 2. Grid Discretization of theta from 0.1 to 0.9
theta_values = np.arange(0.1, 1.0, 0.1)

prior = np.ones(len(theta_values)) / len(theta_values)

# 4. Binomial Log-Likelihood to prevent underflow: ln(L) = s*ln(θ) + (n-s)*ln(1-θ)
log_likelihood = s * np.log(theta_values) + nonsurv * np.log(1 - theta_values)

likelihood = np.exp(log_likelihood_scaled)

print(results.to_string(index=False))

map_index = np.argmax(posterior)
best_theta = theta_values[map_index]

plt.xlabel('Possible Survival Probability (θ)')
plt.ylabel('Probability')
plt.title('Bayesian Parameter Estimation: Female Survival Probability on Titanic')
plt.legend()
plt.grid(True, alpha=0.3)
plt.show()
