 THEORY: Core Theory: PageRank, Markov Chains & The Random Surfer Model
PageRank treats the web as a directed graph where hyperlinks are votes of authority. It models a random surfer who clicks outgoing links with probability d (damping factor, typically 0.85) or jumps to a random page with probability (1 - d). The steady-state visit probability is the principal eigenvector.

[Practical 8 - Network 1] Simulate Random Walk & Compute PageRank on 4-Node Web Graph
======================================================================
PROBLEM:
Construct directed graph G with edges: (A,B), (A,C), (B,C), (B,D), (C,A), (C,D), (D,A), (D,C). 1. Visualize network. 2. Simulate 20-step random walk from 'A'. 3. Count node visits. 4. Compute exact PageRank with nx.pagerank.

PYTHON CODE:
import networkx as nx
import random
import matplotlib.pyplot as plt
from collections import Counter

# Set random seed
random.seed(42)

# Create directed graph
G1 = nx.DiGraph()
edges_1 = [
    ("A", "B"), ("A", "C"),
    ("B", "C"), ("B", "D"),
    ("C", "A"), ("C", "D"),
    ("D", "A"), ("D", "C")
]
G1.add_edges_from(edges_1)

# Visualize Graph
plt.figure(figsize=(7, 5))
pos = nx.spring_layout(G1, seed=42)
nx.draw(G1, pos, with_labels=True, node_color='#38bdf8', node_size=2000, 
        font_size=14, font_weight='bold', arrows=True, arrowsize=20, edge_color='#64748b')
plt.title("Network 1: Directed Webpage Network")
plt.show()

# 2. Simulate Random Walk of 20 steps starting at page 'A'
current = 'A'
walk = [current]
for _ in range(20):
    neighbours = list(G1.successors(current))
    current = random.choice(neighbours)
    walk.append(current)

print("Random Walk Sequence (20 steps):", walk)

# 3. Count visits
visit_counts = Counter(walk)
print("\nVisit Counts during Random Walk:")
for page in sorted(G1.nodes()):
    print(f"Page {page}: {visit_counts[page]} visits")

# 4. Compute PageRank
pagerank_1 = nx.pagerank(G1, alpha=0.85)
print("\n--- Stationary PageRank Scores ---")
for page, score in sorted(pagerank_1.items(), key=lambda x: x[1], reverse=True):
    print(f"Page {page}: {score:.4f} ({score*100:.2f}%)")

VERIFIED OUTPUT:
Random Walk Sequence (20 steps): ['A', 'B', 'C', 'D', 'A', 'B', 'C', 'A', 'B', 'D', 'A', 'B', 'C', 'A', 'B', 'C', 'A', 'C', 'A', 'C', 'D']

Visit Counts during Random Walk:
Page A: 7 visits
Page B: 5 visits
Page C: 6 visits
Page D: 3 visits

--- Stationary PageRank Scores ---
Page C: 0.3246 (32.46%)
Page A: 0.2781 (27.81%)
Page D: 0.2416 (24.16%)
Page B: 0.1557 (15.57%)

VIVA / KEY CONCEPT: Why does Page C have the highest PageRank? Because Page C receives incoming links from both A and B, plus D. Since important pages point to C, C acquires the highest stationary authority.

[Practical 8 - Network 2] PageRank on Alternative Web Topology (25-Step Walk from 'B')
======================================================================
PROBLEM:
Construct directed graph G2 with edges: (A,B), (A,D), (B,C), (B,D), (C,A), (C,D), (D,B). Simulate 25-step random walk starting at 'B'. Compare visit counts and PageRank.

PYTHON CODE:
import networkx as nx
import random
import matplotlib.pyplot as plt
from collections import Counter

random.seed(42)

# Create second directed graph topology
G2 = nx.DiGraph()
edges_2 = [
    ("A", "B"), ("A", "D"),
    ("B", "C"), ("B", "D"),
    ("C", "A"), ("C", "D"),
    ("D", "B")
]
G2.add_edges_from(edges_2)

# Simulate 25-step random walk starting at 'B'
current = 'B'
walk_2 = [current]
for _ in range(25):
    neighbours = list(G2.successors(current))
    current = random.choice(neighbours)
    walk_2.append(current)

print("Random Walk Sequence (25 steps):", walk_2)

# Count visits
visit_counts_2 = Counter(walk_2)
print("\nVisit Counts during Random Walk:")
for page in sorted(G2.nodes()):
    print(f"Page {page}: {visit_counts_2[page]} visits")

# Compute PageRank
pagerank_2 = nx.pagerank(G2, alpha=0.85)
print("\n--- Stationary PageRank Scores ---")
for page, score in sorted(pagerank_2.items(), key=lambda x: x[1], reverse=True):
    print(f"Page {page}: {score:.4f} ({score*100:.2f}%)")

VERIFIED OUTPUT:
Random Walk Sequence (25 steps): ['B', 'C', 'A', 'D', 'B', 'C', 'A', 'B', 'C', 'D', 'B', 'C', 'A', 'B', 'C', 'A', 'B', 'D', 'B', 'D', 'B', 'C', 'A', 'D', 'B', 'D']

Visit Counts during Random Walk:
Page A: 5 visits
Page B: 9 visits
Page C: 6 visits
Page D: 6 visits

--- Stationary PageRank Scores ---
Page B: 0.3640 (36.40%)
Page D: 0.3246 (32.46%)
Page C: 0.1922 (19.22%)
Page A: 0.1192 (11.92%)

VIVA / KEY CONCEPT: Why does Page B rank highest in Network 2? Notice edge (D, B): Node D has only ONE outgoing link, which points directly to B! So 100% of D's high incoming traffic funnels straight into B, driving B to the top rank.
